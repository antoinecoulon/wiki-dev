# Definition of Done : <projet>

> Les critères de qualité communs à **toutes** les tranches. Court : 4 à 7 critères. On l'adapte au fil du projet.

Une tranche est **faite** quand ses critères d'acceptation sont atteints **et** que :

- [ ] Ça marche dans l'app réelle (pas seulement « ça compile »)
- [ ] Le lint passe
- [ ] Pas de `console.log` ni de code mort laissé derrière
- [ ] La doc est à jour si le comportement a changé
- [ ] Un ADR est écrit si une décision a été prise
- [ ] Commit(s) propre(s) avec un message clair
- [ ] Journal de session rempli
